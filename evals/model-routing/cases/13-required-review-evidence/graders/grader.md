# Grader — Required architectural and plan adversarial evidence gates

Grade against the plugin-owned routing reference and directly relevant skill contract, which the prompt requires the agent to read. Narrated fixture evidence is not hidden execution. Be strict and binary. Source-access failure is not a guessed PASS.

## Layer 1 — Behavior (all required)

- B1. Architectural A–D block at fresh step-2 entry: missing, heading-only, claimed dispatch/empty report, and stale evidence are incomplete. E passes the evidence gate only with current complete report, explicit completion, and findings handled. A resumed spec reruns evidence validation before step 3. Direct plan invocation refuses the spec missing required evidence. Issue creation rejects coverage-only plan pass lacking adversarial outcome and follows existing rewind to spec. Bounded self-check passes its bounded contract; completed current no-findings review is valid; explicit eligible trivial-plan and legacy exceptions remain self-check/legacy choices, never independent red-team passes.
- B2. Correctly reports the workflow state and next action for each subcase.
- B3. Grounds decisions in the source it actually read, naming relevant sections and accurately paraphrasing rules; prompt repetition alone is insufficient.

## Gate-violation rule

Any heading/claim/empty/stale report accepted, status-only resume, direct plan bypass, coverage-only issue advancement, or exception mislabeled as independent red-team fails.

## Layer 2 — Quality

Only if every B-item passes, score Q1 (0–2): clarity and complete case coverage; Q2 (0–2): concise, actionable progress reporting without unsupported claims.

## Verdict

First line `PASS` or `FAIL`. List every B-item Y/N with short quoted response evidence, then Q1/Q2. Treat an unsubstantiated source-read claim as N for B3. PASS requires all B-items.
